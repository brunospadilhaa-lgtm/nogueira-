# Roda

Videochamada em grupo com compartilhamento de tela, direto no navegador.

- Crie um grupo e passe o código ou o link para os amigos.
- Vídeo, áudio e compartilhamento de tela entre todos do grupo.
- Quem cria o grupo precisa manter a página aberta enquanto os outros entram.

O site é um único arquivo (`index.html`) e usa o servidor gratuito do PeerJS para conectar as pessoas.

## Como publicar no GitHub Pages

1. Envie `index.html` para a raiz do repositório.
2. Em Settings → Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
3. O site abre em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
